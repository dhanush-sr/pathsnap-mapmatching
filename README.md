# PathSnap: Map-Matching & Route Reconstruction

Matching noisy 1 Hz GPS observations to a road network and reconstructing the driven route.

## Status

| Stage | Status |
|---|---|
| Data loading, cleaning and projection | Done |
| Exploratory data analysis | Done |
| Reference-label alignment, candidate generation, feature engineering | Done |
| Feature selection (correlation, importance, group ablation) | Done |
| Model training and comparison (6 models, untuned) | Done |
| Bayesian hyperparameter optimisation | In progress |
| HMM / Viterbi route reconstruction | Planned |
| FastAPI backend and evaluator UI | Planned |

## Layout

| Path | Contents |
|---|---|
| `pathsnap/data.py` | Raw-file loading, cleaning, local metric projection, road-graph construction |
| `pathsnap/features.py` | Route-to-observation alignment, candidate generation, feature engineering |
| `scripts/eda.py` | Dataset inventory, missing-value analysis, trajectory and network plots, Folium map |
| `scripts/build_dataset.py` | Candidate feature tables for the train and student_test partitions |
| `scripts/feature_selection.py` | Feature correlation, importance and group ablation (train only) |
| `scripts/train_models.py` | Six-model comparison with GroupKFold CV and student-test evaluation |
| `pathsnap/evaluate.py` | Macro F1, precision, recall, log loss, Top-1 accuracy, route continuity |
| `results/eda/` | EDA tables and plots |
| `results/feature_selection/` | Feature selection tables and plots |
| `results/model_comparison.csv`, `results/plots/` | Model comparison results, confusion matrices, training curves |
| `artifacts/models/` | Trained comparison models (Random Forest and KNN are regenerated by the script) |

## Setup

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

Place the dataset so the partitions are at `Student folder/train` and `Student folder/student_test`,
or set `PATHSNAP_DATA` to the folder that contains them.

```bash
python scripts/eda.py
python scripts/build_dataset.py
python scripts/feature_selection.py
python scripts/train_models.py
```

## Model comparison (untuned)

5-fold GroupKFold CV on the 80 training trips; student-test metrics on the 10 student-testing trips.

| Model | Family | CV macro F1 | Test Top-1 | Test macro F1 | Test log loss | Train time (s) |
|---|---|---|---|---|---|---|
| Logistic Regression | Linear | 0.936 | 0.886 | 0.931 | 0.074 | 0.4 |
| Gaussian NB | Probabilistic | 0.900 | 0.874 | 0.902 | 0.387 | 0.05 |
| KNN (k=25) | Instance-based | 0.932 | 0.885 | 0.934 | 0.097 | 0.04 |
| Random Forest | Bagging ensemble | 0.939 | 0.896 | 0.940 | 0.062 | 42.1 |
| LightGBM | Boosting | 0.939 | 0.905 | 0.941 | 0.062 | 3.9 |
| MLP (64-32) | Neural network | 0.934 | 0.897 | 0.938 | 0.065 | 33.4 |
